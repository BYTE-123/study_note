开始记录

个人笔记是一款简洁优雅的在线笔记应用，帮助你记录灵感、沉淀思考、分享好内容——让每一个想法都被珍藏，让每一天都更有意义。

功能

  • 主页：了解产品定位与四大特性，一键开始记录。
  • 笔记管理：新建、保存草稿、发布、编辑、删除，支持状态、关键词与标签筛选。
  • Markdown：源码编辑与实时预览，工具栏一键插入常用语法，渲染时过滤原始 HTML。
  • 分享：生成分享链接、可选访问密码，随时开启或关闭。
  • 评论：作者可开关评论，访客登录后即可参与讨论。
  • 收藏：收藏自己或他人分享的笔记，随时回看。
  • AI 润色：编辑器内划词右键，流式润色，一键替换选区。

技术栈

前端
原生 HTML + CSS + JavaScript（零构建，marked.js 本地引入）
后端
Python 3.10+ / Flask（JSON API + Session 登录态）
数据库
SQLite（参数化查询，外键约束）
AI
DeepSeek（OpenAI 兼容接口，SSE 流式转发）
