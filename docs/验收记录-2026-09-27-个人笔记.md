## 4. 可访问性与视觉令牌核对

### 4.1 对比度（契约 10.5 要求：正文 ≥ 7:1，次要文字/链接 ≥ 4.5:1）

打磨中发现契约给定的 `--color-muted (#8C7B66)`、`--color-primary (#A8894F)` 与契约自身的
AA 要求冲突（实测次要文字 3.98:1、文字链接 3.22:1、主按钮白字 3.30:1）。经确认后按
「保留暖金棕基调、微调至 AA」处理，改动如下：

| 令牌 | 改动前 | 改动后 | 改动前对比度 | 改动后对比度 |
|---|---|---|---|---|
| `--color-primary` | `#A8894F` | `#8A6E3B` | 链接 3.22:1 ✗ | 链接 4.68:1 ✅ |
| `--color-primary-hover` | `#937743` | `#725B2C` | 白字 4.23:1 ✗ | 白字 6.46:1 ✅ |
| `--color-muted` | `#8C7B66` | `#83715B` | 3.98:1 ✗ | 4.57:1 ✅ |
| `--color-success-text` | `#5B7A52` | `#547149` | 「已发布」标签 4.14:1 ✗ | 4.70:1 ✅ |
| `.tag` 文字色 | `muted` | `text` | 3.64:1 ✗ | 6.45:1 ✅ |
| `--color-heading` / `--color-text` / `--color-danger` | 不变 | 不变 | 12.39 / 8.11 / 4.55 | 维持达标 ✅ |

同步把 CSS 中硬编码的 `rgba(168,137,79,…)` 品牌色淡底与 `logo.svg` 线条色更新为新主色。
